    APLICACIÓN EN VIVO

    Un token da un nombre a una decisión reutilizable. Todos estos valores se aplican a la composición y se incluyen en la petición.

    Paleta de referencia Color / Reference palette
    El modo oscuro usa una referencia más clara para el acento y cambia los roles de superficie y texto. La preferencia de movimiento reducido tiene prioridad sobre la duración elegida.
    02

    Del valor al significado

    El color es el mismo en esta cadena; cada nombre expresa una responsabilidad distinta. Los nombres del ejemplo son una convención del laboratorio.

    Una variable de Figma puede representar un token. Un estilo puede agrupar varias propiedades. Un componente utiliza esos valores y añade estructura y comportamiento.
